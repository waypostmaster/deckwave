# Walkthrough: the nine open UI decisions, at the deck

**For the keeper, 2026-10-09.** Each step below ends in one of the decisions
left open in `docs/UI-REVIEW-2026-10-07.md` Part 2 §8. Nothing here edits
the tree; the deck is the instrument, your eye and ear are the readout, and
the answers come back to the desk (see *Record* at the end). Every step has
a DONE line: something you can state or paste. Defaults are marked as
defaults — a default is what the desk would build if you shrug.

**Host and interfaces.** Your desktop browser on `https://deckwave.fm`
(or `http://localhost:8777` — same code since `fdf3e45`), the browser's
console (F12 → Console), and your iPhone for the last section. What you can
see that the desk cannot: the page at your real width, the lock screen, and
whether a transition is tight.

**Halt rule for the whole walk:** a reload destroys the loaded set. Steps 1–5
want a set loaded; do them before anything that reloads (steps 7 and 9).

## Step 1 — §8.6 · should settle's ON state be visible outside the drawer?

Settle is OFF by default and session-only; nothing persists it. The only
open question is whether, when you switch it on, you can still tell with
the drawer closed.

1. Open ⚙, press `settle after a bad blend: off`. It reads `on · Ns`.
2. Close the drawer. Look at the bar and the now-playing card.
   **DONE:** state whether anything on screen says settle is on.
3. **Open ⚙ and press it again to switch it OFF before going on.** Settle
   changes the whole tempo plan downstream and is unheard; leaving it on
   changes every later step of this walk.
   **DONE:** it reads `off`.

**Decision 1:** (a) show an `settle on` mark beside Build while it is on —
**default**; (b) leave it drawer-only.
**HALT:** if step 3 did not return it to `off`, reload (you lose the set)
and start from step 0.

## Step 3 — §8.16 · the scanline overlay

The overlay is a CSS variable read on the deck's host element `#deckwave`
(setting it on `<html>` does NOT reach it — measured 2026-10-09; the host
is where it must go). This turns it off for a look and back on afterwards;
nothing is saved.

1. In the console, paste:

   ```js
   document.getElementById('deckwave').style.setProperty('--dw-scanline-opacity', '0')
   ```

2. Look at the bar text and the panel captions, then the panels.
   **DONE:** state which read better without it: the controls, the panels,
   both, or neither.
3. Restore it:

   ```js
   document.getElementById('deckwave').style.removeProperty('--dw-scanline-opacity')
   ```

   **DONE:** the scanlines are back.

**Decision 3:** (a) limit the overlay to the panel area so the controls are
clean — the review's proposal; (b) keep it everywhere as it is — **default**,
because it changes all ten themes' look and that is your eye, not a count;
(c) lower it everywhere.
